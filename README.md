# Открыть · SprutHub

Пять небольших Android-приложений для открытия замка, двери или ворот через SprutHub одним нажатием. Подходят для автомобильных магнитол и других Android-устройств, где удобнее использовать отдельный значок для каждого действия.

При первом запуске пользователь входит в SprutHub и привязывает нужное устройство. Затем нажатие значка отправляет сохранённую команду без открытия меню управления. После ответа SprutHub на экране на **5 секунд** появляется карточка результата.

Проект не является официальным приложением SprutHub.

## Варианты приложения

Актуальный комплект — **2.5**.

В v2.5 добавлены два отдельных приложения: откатные ворота и калитка. Первые три варианта совпадают с v2.4 по коду и поведению; в них изменён только номер версии. Если v2.4 уже установлена, обновлять эти три приложения необязательно.

| APK | Значок | Заголовок подтверждения |
| --- | --- | --- |
| `Open_Lock_v2.5.apk` | Замок | «Замок открыт» |
| `Open_Garage_v2.5.apk` | Ворота под крышей с горизонтальными полосками | «Ворота открыты» |
| `Open_Swing_v2.5.apk` | Распашные ворота | «Ворота открыты» |

Все пять приложений имеют одинаковые возможности привязки. Значок выбирается по предпочтению: любой вариант можно привязать к поддерживаемому замку, двери или воротам.

Это отдельные приложения с независимыми настройками. Их можно установить одновременно и назначить каждому своё устройство. Название под значком в текущей версии фиксированное и автоматически из SprutHub не подставляется.

## Требования и совместимость

- Android **8.0 или новее**.
- Доступ к интернету.
- Аккаунт SprutHub с правом управления выбранным устройством.
- Android System WebView, способный загрузить веб-интерфейс SprutHub.

Приложение запоминает команду открытия из веб-интерфейса: хаб, ID устройства, ID сервиса, ID характеристики и переданное значение. Заранее заданных адресов конкретного дома в APK нет.

Поддерживаются действия, которые отправляются одной командой `characteristic.update` со значением `intValue` или `boolValue`. Это позволяет работать с воротами, дверями и замками, включая `LockMechanism`, без фиксированных ID сервисов и характеристик.

Сценарии, текстовые команды и действия из нескольких последовательных запросов не поддерживаются. Совместимость со всеми устройствами и лаунчерами не гарантируется.

## Установка и первая привязка

1. Скачайте и установите один или несколько APK. При необходимости разрешите установку из выбранного источника в настройках Android.
2. Запустите приложение и войдите в SprutHub.
3. Выберите свой хаб, комнату и нужное устройство.
4. **Вручную выполните открытие** через интерфейс SprutHub. Это настоящая команда устройству.
5. После успешного ответа появится окно «Запомнить выбранное устройство?».
6. Нажмите **«Сохранить»**, если отправили именно нужную команду открытия. Если выбрали другое действие, нажмите **«Выбрать другое»** и повторите выбор.

После сохранения экран настройки закроется. Следующее нажатие значка отправит сохранённую команду один раз и покажет результат.

> Сохраняйте команду открытия, а не закрытия: приложение повторяет выбранное действие, а не определяет его смысл по названию устройства.

## Как сменить устройство

В правом верхнем углу карточки результата находится кнопка с круговыми стрелками.

1. Нажмите значок приложения и дождитесь карточки результата.
2. В течение **5 секунд** нажмите кнопку с круговыми стрелками.
3. Привязка сбросится и откроется экран настройки.
4. Откройте новое устройство через интерфейс SprutHub и нажмите **«Сохранить»**.

Сброс выполняется сразу, без дополнительного подтверждения. Только угловая кнопка сбрасывает привязку; нажатия на остальную карточку её не меняют. Авторизация сохраняется, пока сессия действительна. Кнопка доступна также в карточке ошибки.

> Обычный запуск сначала отправляет команду ранее привязанному устройству. Кнопка сброса в карточке результата не отменяет уже отправленную команду.

Если выйти из настройки без новой привязки, следующий запуск снова откроет настройку и не отправит команду старому устройству. Альтернативный способ сброса — очистить данные выбранного приложения в настройках Android; в этом случае потребуется повторный вход.

## Что означает подтверждение

Строка **«SprutHub принял команду»** появляется после успешного ответа сервера. При ошибке или отсутствии ответа показывается сообщение об ошибке; автоматическая повторная отправка не выполняется.

Заголовки «Замок открыт», «Калитка открыта» и «Ворота открыты» не являются независимой проверкой физического положения запора или створок. Приложение не опрашивает датчик фактического открытия.

## Обновление

Первые три приложения версии **2.5** устанавливаются поверх соответствующих публичных версий **2.0–2.4**. Откатные ворота и калитка — новые приложения: после установки их нужно отдельно авторизовать и привязать. При совпадении подписи Android сохраняет данные приложения.

- При переходе с **2.0** нужно заново привязать устройство: старый формат не содержал полной команды.
- При переходе с **2.1–2.4** сохранённая привязка сохраняется.
- Персональные сборки **1.x** имеют другие пакеты и не заменяются этими APK.

Для обновления используйте сборку того же варианта приложения. Замена «Замка» на «Распашные ворота» не переносит настройки между ними.

## Если привязка не работает

В нижней строке экрана настройки отображается этап привязки: ожидание ручного открытия, обнаружение команды, ожидание ответа, предложение сохранить или ошибка.

При обращении через Issues приложите:

- Версию APK и выбранный вариант приложения.
- Модель магнитолы или устройства и версию Android.
- Тип управляемого устройства в SprutHub.
- Фото нижней строки после ручного открытия и краткое описание поведения.

Не публикуйте пароли, токены авторизации или резервные копии данных установленного приложения. Диагностика привязки не выводит токен, серийный номер хаба или полный пакет команды.

На некоторых магнитолах меню первоначальной настройки может работать медленно. После привязки для отправки команды этот веб-интерфейс не открывается. Истёкшая или отозванная сессия может потребовать повторной авторизации.

## Конфиденциальность

Публичные APK не содержат заранее встроенных серийных номеров личного хаба, привязок к устройствам владельца, его паролей, токенов или сессий.

Авторизация и привязка сохраняются после настройки на Android-устройстве пользователя, отдельно от установочного APK. Автоматическое резервное копирование данных приложения отключено в манифесте.

Ключ подписи не входит в публичный архив. Он нужен владельцу проекта для выпуска совместимых обновлений и должен храниться отдельно от репозитория и релизов.

## Разработка

Каталоги `source/` содержат проект в формате Apktool: код Smali, JavaScript из `assets/`, Android-ресурсы и манифест. Это не проект Android Studio с исходниками Java/Kotlin и Gradle.

Для пересборки нужны Java и Apktool. Пример для варианта с замком, если `apktool.jar` находится в рабочем каталоге:

```bash
java -jar apktool.jar b source/Lock -o Open_Lock-unsigned.apk
```

Полученный APK необходимо выровнять и подписать инструментами Android. Для обновления поверх опубликованной сборки проекта нужна её исходная подпись. APK, подписанный другим ключом, устанавливается после удаления прежнего приложения либо с другим именем пакета.

Проверки JavaScript запускаются через Node.js из корня распакованного публичного архива:

```bash
node tests/test.cjs
```

Эти проверки используют имитацию WebSocket и ответов SprutHub. Они не заменяют испытания на реальной магнитоле и с реальным устройством.

## Изменения в 2.4

- Явно задан мобильный viewport и масштаб текста WebView.
- На телефонах используется штатная композиция WebView, на больших экранах сохранён программный режим совместимости.
- Диагностика вынесена в отдельную область под страницей, чтобы не перекрывать элементы интерфейса.

Изменения подготовлены для исправления масштаба и выбора дома на смартфоне. 

## Изменения в 2.3

- Исправлен отказ привязки при передаче числовых ID в виде строк.
- Убрана чрезмерно строгая проверка состава значения команды.
- Сопоставление ID запроса и ответа допускает числовую и строковую формы.
- Положение окна сохранения задано без CSS `inset` для совместимости с WebView.
- Добавлены видимые этапы диагностики привязки.

В v2.3 были доступны три варианта значков, карточка результата на 5 секунд и кнопка сброса привязки. Работа v2.3 подтверждена пользователем на автомобильной магнитоле; это не означает проверку всех моделей устройств и версий Android.
